# musician-gig-calculator
Features

Calculates labor costs based on the number of musicians, event duration, and hourly rate.

Includes transportation and other expenses.

Applies a percentage markup.

Shows the estimated total price and price per musician.

Validates user inputs.

Technologies

HTML

CSS

JavaScript

How to use

Open the calculator website.

Enter the number of musicians, event duration, and hourly rate.

Enter transportation costs and other expenses.

Set the desired markup percentage.

Click Calculate price to see the estimate.

Calculation

Labor cost = musicians × event hours × hourly rate

Base cost = labor cost + transportation + other expenses

Total price = base cost × (1 + markup / 100)

Price per musician = total price / number of musicians

Run locally

Download or clone this repository and open index.html in a web browser.
